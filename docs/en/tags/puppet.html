PuppetForge 1.0 (2D puppets on Android)

2D puppet studio for Android (MIT, v1.0 on Oct 20), a free alternative to Character Animator: PNG layers, pivots and bone hierarchy set by touch, live-performed animation, mic-driven lip sync, GIF or MP4 export, all on-device.

L2DEditor (Live2D-style 2D puppet rigging)

Open-source (Apache-2.0) 2D puppet editor, a Cubism alternative published Oct 19: PSD import, meshing and auto-rig, keyforms, physics, .moc3 export without Live2D binaries, plus a CLI and an MCP server so AI agents can drive it.

Found via: GitHub — search “rigging” (repos created since Oct 16)

October 18, 2026

PaperDoll 1.0.0 (Inochi2D puppets in C#)

.NET runtime (BSD-2), 1.0.0 out Oct 17, that loads, animates and draws Inochi2D 2D puppets (.inp, .inx) in FNA or MonoGame: parameters, mesh deformation, masks, physics, several puppets on screen. A from-scratch C# port of Inochi2D and nijilive.

Ayatsuri2D 0.5.3

Open alternative to Live2D Cubism (GPL-3.0, Rust) for real-time 2D puppetry: moc3 v3 to v6 import and export (VTube Studio compatible), open .aom format, runtime embeddable via a C API. Very young: pre-releases, editor still under construction.

October 13, 2026

Iki (web 2D puppet engine)

MIT 2D puppet engine for the web, an alternative to Live2D and Inochi2D: open .iki JSON format, warp mesh, masks, hair physics, editor and auto-rig from PNG/PSD layers, plus an MCP server to have an AI generate the parts. Online demo.
