CEB SAM 3D Body Loader (AI mocap in Blender, now free)

Since Oct 17, Carlos Barreto’s add-on is free: video mocap (GEM-X, SAM 3D Body) in Blender 4.0 to 5.2, retargeting to Auto-Rig Pro, foot-sliding fix, walk along a curve. Windows only; some underlying models are restricted to non-commercial use.

October 17, 2026

CAST (video mocap for any skeleton)

MIT code + CAST Live Blender add-on released Oct 16: captures motion from an RGB video and transfers it in real time to skeletons with a different topology (crab, quadruped…). MIT weights; DINOv3 backbone (Meta licence) and SAM2 to be supplied separately, CUDA GPU required.

Found via: X — post by @Evan_THU (co-author), Oct 16

October 17, 2026

ComfyUI-GEM-X (NVIDIA GEM-X video mocap → FBX)

ComfyUI nodes (Apache-2.0, Oct 15): full-body mocap (77 joints, hands and face) from a single video with NVIDIA GEM-X, then retarget onto Mixamo, Unreal or Unity FBX with a built-in 3D preview. Weights under the NVIDIA Open Model License, ~10 GB of models, NVIDIA GPU required.

Found via: GitHub — search “motion retargeting” (repos created since Oct 14)

October 17, 2026

RigFlow (animation transfer for Maya)

Maya tool (MIT, online Oct 16) that transfers body animation between characters with different proportions and naming: automatic joint matching with a confidence score, manual tweaks, HumanIK preview before baking, face untouched. Alpha, Maya 2023–2024, no release.

Found via: GitHub — topic rigging (sorted by update)

October 16, 2026

@three-ws/retarget

Three.js library (Apache-2.0, published Oct 10) that renames the bones of any GLB humanoid (Mixamo, VRM, Daz, UE, HumanIK, Blender .L/.R…) to a canonical skeleton and retargets your clips onto it with rest pose correction, plus a blending runtime.

Found via: GitHub — search “retarget animation” (repos created since Oct 8)

Rig-GNS Pro 4.6.0

Paid Blender add-on (from $80) for Rigify rigging and retargeting (Mixamo, Rokoko, ActorCore…) for Daz Genesis figures and custom humanoids. 4.6.0 (Oct 11) adds movable landmark markers with symmetry and an editable joint preview before generation.

Found via: Gumroad — Rig-GNS (Pro), 4.6.0 release notes

October 10, 2026

RealMotion Pro 2.0.1

Paid Blender add-on: a library of ready-to-use animations with retargeting to Auto-Rig Pro, Rigify, Mixamo and Daz. v2 switches to the Extension format; 2.0.1 adds customisable thumbnails and better HumanGen integration. Uninstall versions < 2.0 first.
