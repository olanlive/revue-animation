CEB SAM 3D Body Loader (mocap IA dans Blender, devenu gratuit)

Depuis le 17 oct, l’add-on de Carlos Barreto est gratuit : mocap vidéo (GEM-X, SAM 3D Body) dans Blender 4.0 à 5.2, retarget vers Auto-Rig Pro, anti-glissement des pieds, marche sur courbe. Windows seulement ; certains modèles sous-jacents sont limités au non-commercial.

CAST (mocap vidéo pour n’importe quel squelette)

Code MIT + add-on Blender CAST Live publiés le 16 oct : capture le mouvement d’une vidéo RGB et le transfère en temps réel sur des squelettes de topologie différente (crabe, quadrupède…). Poids MIT ; backbone DINOv3 (licence Meta) et SAM2 à fournir à part, GPU CUDA requis.

Trouvé via : X — post de @Evan_THU (co-auteur), 16 oct

ComfyUI-GEM-X (mocap vidéo NVIDIA GEM-X → FBX)

Nœuds ComfyUI (Apache-2.0, 15 oct) : mocap corps entier (77 joints, mains et visage) depuis une seule vidéo avec NVIDIA GEM-X, puis retarget sur des FBX Mixamo, Unreal ou Unity avec aperçu 3D intégré. Poids sous NVIDIA Open Model License, ~10 Go de modèles, GPU NVIDIA requis.

Trouvé via : GitHub — recherche « motion retargeting » (repos créés depuis le 14 oct)

rig-c (rigging 2D compilé, sortie Spine)

Compilateur de rigs 2D (MIT) pensé pour les agents IA : PNG de parties + spec JSON → squelette Spine 4.3 (éditeur payant), vérifié par assertions avant écriture. Le module pose (v0.22.1, 16 oct) transfère une pose issue d’une vidéo sur le rig. Prototype en v0.x.
