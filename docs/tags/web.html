@three-ws/retarget

Lib Three.js (Apache-2.0, publiée le 10 oct) qui renomme les os de n’importe quel humanoïde GLB (Mixamo, VRM, Daz, UE, HumanIK, Blender .L/.R…) vers un squelette canonique et y retargete tes clips avec correction de rest pose, plus un runtime de fondus.

Trouvé via : GitHub — recherche « retarget animation » (repos créés depuis le 8 oct)

Iki (moteur de marionnette 2D web)

Moteur de marionnette 2D pour le web sous MIT, alternative à Live2D et Inochi2D : format JSON ouvert .iki, warp mesh, masques, physique des cheveux, éditeur et auto-rig depuis des calques PNG/PSD, plus un serveur MCP pour faire générer les pièces par une IA. Démo en ligne.
