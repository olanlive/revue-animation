ToothPaste for Blender 1.1.6 (SVG → Grease Pencil)

Blender 5.0+ extension (online Oct 15) that pastes or imports SVG from Illustrator, Figma, Affinity or Inkscape as Grease Pencil v3: editable materials, multi-level masks, layer splitting, partial gradients. CC-BY-4.0 licence, unusual for code.

Moho 14.5 SHOWTIME

Paid 2D animation software: 14.5 (Oct 12, free for Moho 14 owners) adds a Live Playback mode that drives your characters with a webcam (face) or a gamepad via Smart Bones/Actions, recordable as keyframes. Plus a reworked Paint Bucket and magnetic onion skins.

rig-c (compiled 2D rigging, Spine output)

2D rig compiler (MIT) designed for AI agents: part PNGs + JSON spec → Spine 4.3 skeleton (paid editor), checked by assertions before writing. The pose module (v0.22.1, Oct 16) transfers a pose taken from a video onto the rig. v0.x prototype.

Rigby2D

Free 2D skeletal animation editor (MIT), born Oct 13: PSD/PNG import, bones drawn in the viewport, dopesheet + graph editor, IK, JSON/.skel + atlas export compatible with common runtime formats. Tauri app for Win/Mac/Linux, to be compiled (no binary yet).

Grease Pencil Auto Interpolate

Paid Blender add-on ($15, MIT licence) updated Oct 2: automatically interpolates Grease Pencil in-betweens via Geometry Nodes, in real time and non-destructively, plus line-art import and a Link Strokes mode. Blender 4.3–5.2.

Ayatsuri2D 0.5.3

Open alternative to Live2D Cubism (GPL-3.0, Rust) for real-time 2D puppetry: moc3 v3 to v6 import and export (VTube Studio compatible), open .aom format, runtime embeddable via a C API. Very young: pre-releases, editor still under construction.

Iki (web 2D puppet engine)

MIT 2D puppet engine for the web, an alternative to Live2D and Inochi2D: open .iki JSON format, warp mesh, masks, hair physics, editor and auto-rig from PNG/PSD layers, plus an MCP server to have an AI generate the parts. Online demo.
