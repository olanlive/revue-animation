Zeeks Hair 1.0.1

Add-on Blender gratuit (GPL-3.0) qui simplifie la mise en place et le réglage de la dynamique soft body pour cheveux en cartes, strands ou meshes. La 1.0.1 (6 octobre) corrige des erreurs et des bugs de bake. Blender 4.2 LTS et plus.

Trouvé via : Blender Extensions — Zeeks Hair

#blender-addon#simulation#open-source

10 octobre 2026

Blender Animations Plugin 3.1.1 (Roblox)

Add-on Blender open source (GPL-3.0) pour importer et exporter des animations Roblox depuis Blender. La 3.1.1 (9 octobre) corrige les easings et un crash de Blender. Utile pour animer des rigs Roblox avec les outils de Blender.

Trouvé via : GitHub — release 3.1.1

#blender-addon#animation#open-source

8 octobre 2026

OPEN-TOON 0.2.0-experimental

Nouvelle appli d’animation 2D open source (GPL, C++/Qt 6) lancée le 20 sept : dessin vectoriel et brosses MyPaint, timeline/Xsheet, pelure d’oignon, courbes d’animation et rig de perso éditable. Préversions expérimentales macOS et Linux (AppImage) ; projet très jeune.

Trouvé via : Release GitHub — mijim/OPEN-TOON v0.2.0-experimental.11

8 octobre 2026

Krita 5.3.4 / 6.0.4

Krita 5.3.4 (Qt 5) et 6.0.4 (Qt 6, Wayland et HDR sous Linux), sorties le 15 sept : la version Android exporte enfin en vidéo les animations image par image et les timelapses, avec une salve de correctifs. L’import XCF de GIMP est retiré (dépendance non maintenue).

Trouvé via : Annonce Krita — Krita 5.3.4 Released!

8 octobre 2026

CloudRig 2.2.31

Le générateur de rigs du Blender Studio (gratuit, GPL) passe en 2.2.31 le 5 oct : génération 2 à 5× plus rapide (le gain dépend de la complexité du fichier, surtout avec Blender 5.3) et composant « Chain: Layered » peaufiné sur le film Cowboi. Pour Blender 5.0 à 5.x.

Trouvé via : Blender Extensions — CloudRig, historique des versions (2.2.31)

#blender-addon#rigging#open-source

8 octobre 2026

LibreSprite 1.3

Éditeur de sprites animés et de pixel art libre (GPLv2, fork d’Aseprite) : la 1.3 du 2 oct est la première depuis mars 2025. Brosses jusqu’à 256 px, symétrie étendue, raccourci mode tuilé, meilleure gestion hi-DPI et correctifs de sécurité (zip-slip, sandbox des scripts).

Trouvé via : Release GitHub — LibreSprite v1.3

#2d#pixel-art#open-source

8 octobre 2026

FreeMoCap 2.0.0-alpha.25

Mocap sans marqueurs libre (AGPL) à partir de webcams : l’alpha 25 du 24 sept ajoute des options d’export Blender dans l’interface, améliore la détection des mains et corrige l’usage sur machines sans GPU. Installeurs Windows/macOS/Linux, mais c’est une alpha : prudence.

Trouvé via : Release GitHub — freemocap v2.0.0-alpha.25
