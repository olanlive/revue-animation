Pixel Puppettier (layer-based rigging for Aseprite)

Released Oct 22 (MIT): Aseprite extension that attaches bones to layers, with hierarchy and mouse posing; “Create frame” builds a new frame where each part stays on its own layer for pixel-art cleanup. UI in Spanish.
