KinetiFrame (2D animation studio for Android)

Released Oct 21: Apache-2.0 Android app mixing frame-by-frame drawing (onion skin, layers) with IK-rigged characters, finger-recorded performances, camera moves, audio and MP4 export. Offline, no account; still in development, no stable release yet.

PuppetForge 1.0 (2D puppets on Android)

2D puppet studio for Android (MIT, v1.0 on Oct 20), a free alternative to Character Animator: PNG layers, pivots and bone hierarchy set by touch, live-performed animation, mic-driven lip sync, GIF or MP4 export, all on-device.
