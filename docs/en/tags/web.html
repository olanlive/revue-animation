ActionForge (auto-rig and animation in the browser)

Free beta spotted Oct 29, no install or account: load an unrigged GLB/FBX character, it auto-rigs it, you layer Quaternius CC0 clips per body part, fix with IK and export with UE5, Unity, Godot or Blender presets. Proprietary code.

Found via: X — post by @gamedevunchaind (Oct 29)

October 31, 2026

Stick Figure Studio (rigged 2D animation in the browser)

Created Oct 30, MIT: a 2D animation studio in a single index.html, offline and dependency-free. A stick figure acts as the hidden rig under your artwork, with IK, timeline, camera, sound and MP4 export, plus an MCP server so an AI agent can drive scenes.

LAK 2.0.0 (inspect a mocap clip in the browser)

First public release (Oct 29), Apache-2.0: open an FBX or GLB clip (mocap, keyframed or AI), step through it with joint trails, let it flag pops, jitter and rotation flips, then trim and re-export it. Everything stays on your device.

OrthoRig 0.2.0 (2D rigs from Blender to PixiJS)

Version 0.2.0 on Oct 25 (MIT): build an orthographic 2D skeleton in Blender and it compiles it for PixiJS v8 with 2-bone IK, look-at, sockets, timeline events from markers, additive layers and a spritesheet baker.

Prima Motion Capture Volume Planner (mocap camera placement)

Published Oct 24 (AGPL-3.0 plus extra terms, name and logo not licensed): single-file web app to plan optical mocap camera placement (OptiTrack, Qualisys, Vicon), coverage, marker visibility and predicted 3D error. Geometric model only.

three-procedural-locomotion

Released Oct 22 (MIT): procedural human locomotion for Three.js with no baked clips. Walk, run, turns, crouch and jump computed every frame (footstep planning, two-bone IK, feet on terrain), tuned against CMU mocap.

Ekza Animator (glTF/VRM character animation in the browser)

Open-source (MIT, alpha) in-browser character animator launched Oct 18: circle controls and leg IK on a GLB or VRM, Dope Sheet, a Graph Editor with Maya-style tangents, then bake back into the original file or export VRMA.

October 16, 2026

@three-ws/retarget

Three.js library (Apache-2.0, published Oct 10) that renames the bones of any GLB humanoid (Mixamo, VRM, Daz, UE, HumanIK, Blender .L/.R…) to a canonical skeleton and retargets your clips onto it with rest pose correction, plus a blending runtime.

Found via: GitHub — search “retarget animation” (repos created since Oct 8)

October 13, 2026

Iki (web 2D puppet engine)

MIT 2D puppet engine for the web, an alternative to Live2D and Inochi2D: open .iki JSON format, warp mesh, masks, hair physics, editor and auto-rig from PNG/PSD layers, plus an MCP server to have an AI generate the parts. Online demo.
