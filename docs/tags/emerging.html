PhoneRig for Blender 1.1.0

Nouveau (11 oct), gratuit et GPL-3.0 : un téléphone Android devient caméra virtuelle 6DoF pour Blender via ARCore, avec retour vidéo, enregistrement de prises en keyframes, bake en F-curves propres et presets (épaule, dolly, grue). Wi-Fi local, Blender 4.2+.

13 octobre 2026

MeshRig 0.2.0

Nouvelle appli autonome gratuite (GPL-3.0, Windows/macOS/Linux) qui rigge un mesh de .blend : squelette humanoïde, quadrupède ou chaîne calé dans le volume, poids calculés à travers le volume, brosse de poids, IK auto et test de pose. Pilote Blender (testé 5.2) en tâche de fond.

Trouvé via : GitHub — topic rigging (mis à jour récemment)

13 octobre 2026

Ayatsuri2D 0.5.3

Alternative ouverte à Live2D Cubism (GPL-3.0, Rust) pour la marionnette 2D temps réel : import et export moc3 v3 à v6 (compatible VTube Studio), format ouvert .aom, runtime embarquable via une API C. Très jeune : préversions, éditeur encore en chantier.

Trouvé via : GitHub — topic rigging (mis à jour récemment)

13 octobre 2026

Iki (moteur de marionnette 2D web)

Moteur de marionnette 2D pour le web sous MIT, alternative à Live2D et Inochi2D : format JSON ouvert .iki, warp mesh, masques, physique des cheveux, éditeur et auto-rig depuis des calques PNG/PSD, plus un serveur MCP pour faire générer les pièces par une IA. Démo en ligne.

Trouvé via : GitHub — topic rigging (mis à jour récemment)

Riginsec

Nouvel add-on Blender gratuit (Gumroad, prix libre) sorti le 5 octobre : il rigge une surface et génère ses poids en quelques secondes pour l’animer tout de suite. Projet tout jeune, peu documenté et licence non précisée : à tester sur un fichier de travail.

Trouvé via : Blender Artists — annonce de Riginsec

OPEN-TOON 0.2.0-experimental

Nouvelle appli d’animation 2D open source (GPL, C++/Qt 6) lancée le 20 sept : dessin vectoriel et brosses MyPaint, timeline/Xsheet, pelure d’oignon, courbes d’animation et rig de perso éditable. Préversions expérimentales macOS et Linux (AppImage) ; projet très jeune.

Trouvé via : Release GitHub — mijim/OPEN-TOON v0.2.0-experimental.11

FlowHMR

Mocap depuis une seule vidéo : FlowHMR (code et poids publiés fin sept, article arXiv en oct) génère un mouvement 3D global corps + mains physiquement plausible, avec démo web et export FBX. Licence recherche : usage commercial interdit.
