mmd-retarget 0.0.2 (VMD from one model to another, without clipping)

Created Oct 23 (GPL-3.0, Python, VMD ↔ Blender): retargets an MMD dance to another body with scaling, foot locking and arm IK, then detects frame-by-frame interpenetration with CSV/JSON reports. Very early, docs in Chinese.

cascadeur MMD toolkit 1.0 (VMD in Cascadeur)

Free Cascadeur plugin (v1.0 on Oct 19, Windows): import MMD .vmd motions onto your characters, export VMD as FK or IK and clean up the generated rig. Heads-up: no license, binary only, the repo holds just the docs.
