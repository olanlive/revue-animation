mmdance 0.1.0 (MMD dances on a Mixamo character in Blender)

Released Oct 26 under MIT: a headless Python pipeline for Blender 5.2 that retargets a MikuMikuDance VMD onto a Mixamo, Tripo, Meshy or AccuRig character, with camera, face (blinks, lip-sync) and skirt and hair physics, then renders the video.

OrthoRig 0.2.0 (2D rigs from Blender to PixiJS)

Version 0.2.0 on Oct 25 (MIT): build an orthographic 2D skeleton in Blender and it compiles it for PixiJS v8 with 2-bone IK, look-at, sockets, timeline events from markers, additive layers and a spritesheet baker.

October 24, 2026

mmd-retarget 0.0.2 (VMD from one model to another, without clipping)

Created Oct 23 (GPL-3.0, Python, VMD ↔ Blender): retargets an MMD dance to another body with scaling, foot locking and arm IK, then detects frame-by-frame interpenetration with CSV/JSON reports. Very early, docs in Chinese.

October 23, 2026

Batlejka (multi-camera sync → FreeMoCap → .blend)

Released Oct 21 (AGPL-3.0): drop the clips of a multi-camera mocap session (phones, no timecode), it syncs them by audio, lets you cut takes, then runs FreeMoCap to get 3D skeletons all the way to a .blend file.

Found via: GitHub — search “mocap” (repos created since Oct 20)

October 21, 2026

QuadMocap (AI video mocap for any rig)

Local web app (MIT, published Oct 20): give it a rigged character, it trains a DINOv2 detector on renders of your rig, then fits the skeleton to a two-view AI video. Outputs a Blender Action, .blend and FBX; tested on quadrupeds.

Found via: GitHub — search “motion capture” (repos created since Oct 19)

October 20, 2026

Riggle 0.1.1 (rig + jiggle bones, Blender-powered)

Local rigging workbench (MIT, heavy WIP) driven by Blender: fit a 22-joint humanoid skeleton to your mesh, mark what should wobble (jiggle bones), then export rigged GLB + FBX with a spring manifest. Portable Windows build on Oct 19.

October 13, 2026

MeshRig 0.2.0

New free standalone app (GPL-3.0, Windows/macOS/Linux) that rigs a mesh from a .blend: humanoid, quadruped or chain skeleton fitted inside the volume, weights computed through the volume, weight brush, auto IK and pose test. Drives Blender (tested on 5.2) in the background.

Found via: GitHub — topic rigging (recently updated)

October 8, 2026

Blender 5.3 — Grease Pencil: Carver tool and selection in Draw mode

Blender 5.3 (beta imminent, release planned for Nov 10) beefs up Grease Pencil: lasso/box selection and copy-paste without leaving Draw mode, a Carver tool that cuts strokes and fills as a true boolean, multi-region fill in a single gesture and cyclic strokes.

October 8, 2026

Blender 5.3 — Animation & Rigging: rotation mode conversion

On the animation side, Blender 5.3 finally converts animation natively from one rotation mode to another (Ctrl+R in Pose mode, replacing Rigify’s operator), adds an influence slider to pose pasting, extends Fix to Camera to focal length and pauses playback while scrubbing.

Found via: Devtalk — Animation & Rigging module meeting, Oct 1, 2026
