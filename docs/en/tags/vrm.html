Ekza Animator (glTF/VRM character animation in the browser)

Open-source (MIT, alpha) in-browser character animator launched Oct 18: circle controls and leg IK on a GLB or VRM, Dope Sheet, a Graph Editor with Maya-style tangents, then bake back into the original file or export VRMA.

Lightweight CPU VTuber Tracker 0.1.0 (GPU-free webcam VRM mocap)

Native Windows webcam tracker in Rust (v0.1.0, Oct 19) that drives a VRM avatar on the CPU alone: 52 ARKit blendshapes, gaze, arms, torso and fingers at 30 fps. Code is Apache-2.0/MIT, but the bundled body model is under the SAM License: read it before pro use.

XR Animator 0.36.0 (AI webcam mocap)

Full-body webcam mocap (MediaPipe) for VRM/MMD avatars, web or desktop: 0.36.0 (Oct 17) adds a faster “lite” body model, a GPU/CPU choice and local web app mode on Android and iOS. Free, but the repo declares no license.

VRM Add-on for Blender 4.10.2

Import/export and editing of VRM avatars in Blender (GPL-3.0 / MIT). 4.10.0 (Oct 10) adds experimental support for spring bone limits; 4.10.1 and 4.10.2 fix expressions/blend shapes detached on VRM0/VRM1 import. Blender 4.2 to 5.2.
