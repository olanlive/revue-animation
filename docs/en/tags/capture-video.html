CAST (mocap vidéo pour n’importe quel squelette)

Code MIT + add-on Blender CAST Live publiés le 16 oct : capture le mouvement d’une vidéo RGB et le transfère en temps réel sur des squelettes de topologie différente (crabe, quadrupède…). Poids MIT ; backbone DINOv3 (licence Meta) et SAM2 à fournir à part, GPU CUDA requis.

Found via: X — post de @Evan_THU (co-auteur), 16 oct

ComfyUI-GEM-X (mocap vidéo NVIDIA GEM-X → FBX)

Nœuds ComfyUI (Apache-2.0, 15 oct) : mocap corps entier (77 joints, mains et visage) depuis une seule vidéo avec NVIDIA GEM-X, puis retarget sur des FBX Mixamo, Unreal ou Unity avec aperçu 3D intégré. Poids sous NVIDIA Open Model License, ~10 Go de modèles, GPU NVIDIA requis.

Found via: GitHub — recherche « motion retargeting » (repos créés depuis le 14 oct)

aimocap 0.5.0 (vidéo → mocap MetaHuman, UE 5.8)

Plugin UE 5.8 + CLI (MIT, 15 oct) : vidéo → mocap à deux via GVHMR (licence non commerciale), nettoyage du glissement des pieds, retarget MetaHuman, séquence et rapport QC auto. Génération vidéo Seedance payante en crédits ; testé seulement Win 11/RTX 3090, doc en chinois.

October 15, 2026

Kinesia

Mocap 3D multi-personnes depuis une seule vidéo (code CC0) : SAM 3.1 + SAM 3D Body + DINOv3, suivi et ré-identification, pieds ancrés au sol, viewer web. Lourd (Linux, GPU NVIDIA ~32 Go), modèles Meta sous licence SAM restrictive, export CSV/JSON (pas de BVH/FBX annoncé).

SAM3DBody-cpp

Moteur C++ sans Python pour SAM 3D Body : mocap 3D temps réel depuis une seule caméra, multi-personnes, export BVH par acteur prêt pour Blender (script fourni). Code MIT ; poids issus du modèle SAM 3D Body de Meta, vérifier sa licence avant usage commercial.

PhoneRig for Blender 1.1.0

Nouveau (11 oct), gratuit et GPL-3.0 : un téléphone Android devient caméra virtuelle 6DoF pour Blender via ARCore, avec retour vidéo, enregistrement de prises en keyframes, bake en F-curves propres et presets (épaule, dolly, grue). Wi-Fi local, Blender 4.2+.

CV Auto Track 1.0.4

Add-on Blender libre (GPL-3.0) : auto-tracking OpenCV dans le Movie Clip Editor, presets Fast/Dynamic/High Motion, track + solve + raffinage en un clic, filtrage des pistes instables et prise en compte des masques. La 1.0.4 (12 oct) corrige le suivi des masques parentés.
