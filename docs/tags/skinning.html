Riggle 0.1.1 (rig + jiggle bones, moteur Blender)

Atelier de rigging local (MIT, très WIP) piloté par Blender : tu cales un squelette humanoïde de 22 os sur ton mesh, tu marques ce qui doit ballotter (jiggle bones), puis export GLB + FBX riggés avec un manifeste de ressorts. Build Windows portable le 19 oct.

MeshRig 0.2.0

Nouvelle appli autonome gratuite (GPL-3.0, Windows/macOS/Linux) qui rigge un mesh de .blend : squelette humanoïde, quadrupède ou chaîne calé dans le volume, poids calculés à travers le volume, brosse de poids, IK auto et test de pose. Pilote Blender (testé 5.2) en tâche de fond.
