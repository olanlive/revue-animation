Aseprite 1.3.18.6

Mise à jour de l’éditeur de pixel art et d’animation sprite : correction du crash au collage de tilemaps, export JSON de sprite sheets corrigé, améliorations X11 sous Linux. Code source disponible mais licence non libre ; binaires payants (compilation perso autorisée).

Blender 5.3 — Grease Pencil : outil Carver et sélection en mode Draw

Blender 5.3 (bêta imminente, sortie prévue le 10 nov) muscle Grease Pencil : sélection lasso/boîte et copier-coller sans quitter le mode Draw, outil Carver qui découpe traits et remplissages en vraie booléenne, remplissage multi-régions d’un seul geste et traits cycliques.

8 octobre 2026

OPEN-TOON 0.2.0-experimental

Nouvelle appli d’animation 2D open source (GPL, C++/Qt 6) lancée le 20 sept : dessin vectoriel et brosses MyPaint, timeline/Xsheet, pelure d’oignon, courbes d’animation et rig de perso éditable. Préversions expérimentales macOS et Linux (AppImage) ; projet très jeune.

Trouvé via : Release GitHub — mijim/OPEN-TOON v0.2.0-experimental.11

Krita 5.3.4 / 6.0.4

Krita 5.3.4 (Qt 5) et 6.0.4 (Qt 6, Wayland et HDR sous Linux), sorties le 15 sept : la version Android exporte enfin en vidéo les animations image par image et les timelapses, avec une salve de correctifs. L’import XCF de GIMP est retiré (dépendance non maintenue).

Trouvé via : Annonce Krita — Krita 5.3.4 Released!

8 octobre 2026

LibreSprite 1.3

Éditeur de sprites animés et de pixel art libre (GPLv2, fork d’Aseprite) : la 1.3 du 2 oct est la première depuis mars 2025. Brosses jusqu’à 256 px, symétrie étendue, raccourci mode tuilé, meilleure gestion hi-DPI et correctifs de sécurité (zip-slip, sandbox des scripts).

Trouvé via : Release GitHub — LibreSprite v1.3
