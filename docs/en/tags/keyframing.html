Ekza Animator (glTF/VRM character animation in the browser)

Open-source (MIT, alpha) in-browser character animator launched Oct 18: circle controls and leg IK on a GLB or VRM, Dope Sheet, a Graph Editor with Maya-style tangents, then bake back into the original file or export VRMA.

October 19, 2026

MotionForge 1.0.1 (2D animation studio for Windows)

Flash-style vector 2D animation studio (MIT, C#/.NET 10, Windows) released Oct 19: keyframe timeline with eased tweens, layers, symbols, onion skin, GIF, PNG, sprite sheet and SVG export. 1.0.1 smooths the brush and adds an HSV wheel.

Found via: GitHub — search “topic:animation topic:blender” (updated since Oct 17)

October 8, 2026

Blender 5.3 — Animation & Rigging: rotation mode conversion

On the animation side, Blender 5.3 finally converts animation natively from one rotation mode to another (Ctrl+R in Pose mode, replacing Rigify’s operator), adds an influence slider to pose pasting, extends Fix to Camera to focal length and pauses playback while scrubbing.

Found via: Devtalk — Animation & Rigging module meeting, Oct 1, 2026
