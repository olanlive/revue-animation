Rigger 1.2.0 (Blender auto-rig + video to animation)

Modular auto-rigger for Blender 4.2+ (GPL-3.0): 1.2.0 (Oct 18) adds local video-to-animation (body, fingers, ARKit shape keys, root motion, planted feet), AI-placed markers and a picker right in the 3D viewport.

XR Animator 0.36.0 (AI webcam mocap)

Full-body webcam mocap (MediaPipe) for VRM/MMD avatars, web or desktop: 0.36.0 (Oct 17) adds a faster “lite” body model, a GPU/CPU choice and local web app mode on Android and iOS. Free, but the repo declares no license.

L2DEditor (Live2D-style 2D puppet rigging)

Open-source (Apache-2.0) 2D puppet editor, a Cubism alternative published Oct 19: PSD import, meshing and auto-rig, keyforms, physics, .moc3 export without Live2D binaries, plus a CLI and an MCP server so AI agents can drive it.

October 18, 2026

CEB SAM 3D Body Loader (AI mocap in Blender, now free)

Since Oct 17, Carlos Barreto’s add-on is free: video mocap (GEM-X, SAM 3D Body) in Blender 4.0 to 5.2, retargeting to Auto-Rig Pro, foot-sliding fix, walk along a curve. Windows only; some underlying models are restricted to non-commercial use.

October 17, 2026

CAST (video mocap for any skeleton)

MIT code + CAST Live Blender add-on released Oct 16: captures motion from an RGB video and transfers it in real time to skeletons with a different topology (crab, quadruped…). MIT weights; DINOv3 backbone (Meta licence) and SAM2 to be supplied separately, CUDA GPU required.

Found via: X — post by @Evan_THU (co-author), Oct 16

October 17, 2026

ComfyUI-GEM-X (NVIDIA GEM-X video mocap → FBX)

ComfyUI nodes (Apache-2.0, Oct 15): full-body mocap (77 joints, hands and face) from a single video with NVIDIA GEM-X, then retarget onto Mixamo, Unreal or Unity FBX with a built-in 3D preview. Weights under the NVIDIA Open Model License, ~10 GB of models, NVIDIA GPU required.

Found via: GitHub — search “motion retargeting” (repos created since Oct 14)

October 16, 2026

rig-c (compiled 2D rigging, Spine output)

2D rig compiler (MIT) designed for AI agents: part PNGs + JSON spec → Spine 4.3 skeleton (paid editor), checked by assertions before writing. The pose module (v0.22.1, Oct 16) transfers a pose taken from a video onto the rig. v0.x prototype.
