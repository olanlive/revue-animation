XR Animator 0.36.0 (mocap webcam IA)

CEB SAM 3D Body Loader (mocap IA dans Blender, devenu gratuit)

Depuis le 17 oct, l’add-on de Carlos Barreto est gratuit : mocap vidéo (GEM-X, SAM 3D Body) dans Blender 4.0 à 5.2, retarget vers Auto-Rig Pro, anti-glissement des pieds, marche sur courbe. Windows seulement ; certains modèles sous-jacents sont limités au non-commercial.
