three-procedural-locomotion

Released Oct 22 (MIT): procedural human locomotion for Three.js with no baked clips. Walk, run, turns, crouch and jump computed every frame (footstep planning, two-bone IK, feet on terrain), tuned against CMU mocap.

cascadeur MMD toolkit 1.0 (VMD in Cascadeur)

Free Cascadeur plugin (v1.0 on Oct 19, Windows): import MMD .vmd motions onto your characters, export VMD as FK or IK and clean up the generated rig. Heads-up: no license, binary only, the repo holds just the docs.

Ekza Animator (glTF/VRM character animation in the browser)

Open-source (MIT, alpha) in-browser character animator launched Oct 18: circle controls and leg IK on a GLB or VRM, Dope Sheet, a Graph Editor with Maya-style tangents, then bake back into the original file or export VRMA.

Viewport Avatar Toolset 0.4.1 (Bento animation for Second Life)

Free, open-source animation editor (LGPL-2.1, Linux and Windows) for Second Life’s Bento avatar: timeline, IK, graph editor, BVH, glTF, FBX or network mocap import, .anim and BVH export. Version 0.4 (Oct 17) resizes the whole skeleton and scales the keys.

October 17, 2026

RigFlow (animation transfer for Maya)

Maya tool (MIT, online Oct 16) that transfers body animation between characters with different proportions and naming: automatic joint matching with a confidence score, manual tweaks, HumanIK preview before baking, face untouched. Alpha, Maya 2023–2024, no release.

October 15, 2026

Driver Espresso Lite 1.6.6

Free Blender add-on (GPL-3.0): 18 ready-to-use driver “recipes” (oscillation, blinking, looping rotation, fades, ease/spring, RGB neons) with a live curve preview and offset across several objects or bones. Native drivers: the animation survives uninstalling.

October 15, 2026

KeyCraft MIDI 1.4.0

Free Blender add-on (GPL-3.0) that generates a piano/synth keyboard and animates it from a MIDI controller, recorded as editable keyframes. 1.4.0 (Oct 14) handles existing keyboards, multi-channel, organ and MIDI/MusicXML/PDF playback. Live MIDI on Windows only.

mGear 5.4.0

Free Maya rigging framework (MIT): 5.4 (Oct 14) adds Facial Rigger 3.0 (unified eyes/lips/brows), Anim Picker 2.0 (SVG, widgets), Blocking Ghosts (3D onion skinning), Spring Manager 2.0 and ~2× faster Shifter builds. Maya 2022–2027.
